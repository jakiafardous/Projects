### **Design and Simulation of a Triple-Waveform Function Generator Using μA741 Operational Amplifiers**

This project focuses on designing a signal generator that produces three different types of electrical waveforms: **square, triangular, and sine waves**, using μA741 operational amplifiers.

The circuit works in three stages:

1. **Square Wave Generation:** An astable multivibrator generates a square wave at an adjustable frequency of 50 Hz to 2 kHz.
2. **Triangular Wave Generation:** An integrator circuit converts the square wave into a triangular wave.
3. **Sine Wave Generation:** An active low-pass filter removes unwanted harmonics from the triangular wave to produce a smoother sine wave.

The circuit is designed and tested using **LTSpice simulation software** to verify its performance and waveform outputs.
